Built for self-hosting

Keep the platform and architecture data under your control.

OpenEA Community uses a conventional Python and PostgreSQL architecture with Docker Compose as the supported deployment path. The core platform does not require an externally hosted SaaS service.

Python FastAPI PostgreSQL SQLAlchemy Jinja2 HTMX Docker Compose
