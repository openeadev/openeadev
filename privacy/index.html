Privacy & Analytics

Last updated: August 26, 2026

OpenEA uses optional website analytics on openea.dev to understand how visitors use the public project website. Analytics is disabled by default. Google Analytics is loaded only after you choose Allow analytics.

What we use

The site uses Google Analytics 4 with measurement ID G-VBNM5LKVBF. We use analytics to understand page usage and a small set of project interactions, including visits to Try OpenEA, the live demo, GitHub, documentation, downloads, and releases.

What happens before consent

OpenEA uses Basic Consent Mode. Until you allow analytics, the Google Analytics tag is not loaded and no Google Analytics data is sent from this site. Advertising storage, advertising user data, and advertising personalization are configured as denied even when analytics is allowed.

What may be collected after consent

If you allow analytics, Google Analytics may process information such as pages viewed, approximate location, browser and device characteristics, referring pages, session activity, and interactions with selected links. Google Analytics may set first-party analytics cookies such as _ga.

OpenEA also records these custom analytics events when applicable:

  • try_openea — a visitor follows a Try OpenEA link.
  • demo_launch — a visitor opens the OpenEA Community demo.
  • github_visit — a visitor follows a GitHub link.
  • docs_open — a visitor opens documentation.
  • download_open — a visitor opens the download area.
  • releases_open — a visitor opens release information.

Your preference

Your analytics choice is stored in your browser's local storage under openea.analyticsConsent.v1. This preference is used so the site can remember whether you allowed or declined analytics. If you clear browser site data, the site will ask again.

You can change your choice at any time. If you disable analytics after previously allowing it, the site removes the common Google Analytics cookies it can access and reloads with the Google tag blocked.

Google and GitHub

Google Analytics is provided by Google. You can review Google's privacy policy for information about Google's data practices. This website is hosted with GitHub Pages, so GitHub may separately process technical connection information as part of providing the hosting service.

Scope

This notice describes analytics on openea.dev. Links to GitHub, demo.openea.dev, and other external services lead to separate services with their own data practices.

Questions

Questions about the OpenEA website can be raised through the OpenEA Community repository on GitHub.
